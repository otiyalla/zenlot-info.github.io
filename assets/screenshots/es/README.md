# Spanish screenshots

`es/index.html` references `plan.png`, `journal.png` and `history.png` in this
folder — the same three filenames as the English set one level up.

Until you drop the files in, each device frame on the Spanish page shows the
branded placeholder (same graceful fallback as `fr/` had before its screenshots
were added). Capture guidance is identical to `assets/screenshots/README.md`;
use the app in Spanish and dark mode.
